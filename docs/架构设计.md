## 2. 模块职责

### 2.1 config.py — 配置管理(Pydantic Settings)

使用 Pydantic Settings 管理所有可配置项, 支持环境变量覆盖(前缀 `ANIME_`):

| 配置项 | 默认值 | 环境变量 | 说明 |
|--------|--------|---------|------|
| db_path | `data/anime.db` | ANIME_DB_PATH | 数据库文件路径 |
| exports_dir | `data/exports` | ANIME_EXPORTS_DIR | 导出产物目录 |
| tracking_file | `data/tracking.csv` | ANIME_TRACKING_FILE | 追踪目标CSV文件 |
| request_delay | 0.4 | ANIME_REQUEST_DELAY | 请求间隔(秒) |
| max_concurrency | 20 | ANIME_MAX_CONCURRENCY | 最大并发API请求数 |
| max_connections | 50 | ANIME_MAX_CONNECTIONS | HTTP连接池大小 |
| request_timeout | 15.0 | ANIME_REQUEST_TIMEOUT | 请求超时(秒) |
| max_retries | 3 | ANIME_MAX_RETRIES | 失败重试次数 |
| retry_wait | 2.0 | ANIME_RETRY_WAIT | 初始重试等待(秒) |
| interval_airing_minutes | 60 | ANIME_INTERVAL_AIRING_MINUTES | 在播动画采集间隔 |
| interval_finished_hours | 24 | ANIME_INTERVAL_FINISHED_HOURS | 完结动画采集间隔 |
| schedule_check_seconds | 60 | ANIME_SCHEDULE_CHECK_SECONDS | 调度器检查间隔 |
| log_level | INFO | ANIME_LOG_LEVEL | 日志级别 |

### 2.2 client/ — API客户端层

```
client/
├── __init__.py           → 导出 BilibiliClient, ClientFactory
├── base.py               → BaseClient ABC(5个抽象方法)
├── factory.py            → ClientFactory(懒加载注册表)
└── bilibili/
    ├── __init__.py        → 导出 BilibiliClient 及类型
    ├── client.py          → BilibiliClient(BaseClient) httpx.AsyncClient
    └── types.py           → B站 Pydantic 响应模型
```

**BaseClient** — 抽象基类, 定义客户端契约:

```python
class BaseClient(ABC):
    async def search(keyword) → list         # 搜索
    async def get_season_info(id) → Any      # 内容详情
    async def get_season_stat(id) → Any      # 内容统计
    async def get_video_stat(aid, bvid) → Any# 单集统计
    async def get_video_stats_batch(ids) → list  # 批量单集统计
    async def close()                        # 关闭连接
```

**ClientFactory** — 客户端工厂, 支持懒加载和动态注册:

```python
ClientFactory.register("bilibili", "anime_hub.client.bilibili.client:BilibiliClient")
client = ClientFactory.create("bilibili")
```

**BilibiliClient(BaseClient)** — B站客户端:

```
search(keyword)            → list[SearchResult]
get_season_info(season_id) → SeasonInfo | None
get_season_stat(season_id) → SeasonStat | None
get_video_stat(aid/bvid)   → VideoStat | None
get_video_stats_batch(aids)→ list[VideoStat | None]
```

**扩展新平台的流程:**

```
1. 创建 client/iqiyi/ 目录
   ├── __init__.py
   ├── client.py    → IqiyiClient(BaseClient)
   └── types.py     → Pydantic 模型
2. ClientFactory.register("iqiyi", "...:IqiyiClient")
3. Pipeline 中添加 _transform_iqiyi_detail()
```

### 2.3 models/ — 数据模型层

5 个 SQLAlchemy 2.0 ORM 模型:

```
models/
├── __init__.py        → 导出所有模型
├── base.py            → Base, TimestampMixin
├── anime.py           → Anime(动画主表, season_id PK, platform 标识)
├── anime_stat.py      → AnimeStat(动画统计快照)
├── episode.py         → Episode(单集主表, ep_id PK)
├── episode_stat.py    → EpisodeStat(单集统计快照)
└── crawl_task.py      → CrawlTask(采集任务表, 含 platform/paused)
```

**关系模型:**

```
Anime (1) ──── (N) AnimeStat      一部动画 → 多个统计快照
Anime (1) ──── (N) Episode        一部动画 → 多集
Anime (1) ──── (N) CrawlTask      一部动画 → 一个采集任务
Episode (1) ── (N) EpisodeStat    一集 → 多个统计快照
```

**CrawlTask 关键字段:**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer PK AUTO | 自增主键 |
| platform | String(20) INDEX | 来源平台(bilibili/iqiyi/tencent) |
| season_id | BigInteger UNIQUE | 动画平台ID |
| title | String(200) | 动画标题(冗余) |
| status | String(20) | pending/running/success/failed |
| priority | Integer | 0=在播, 1=普通, 2=低频 |
| interval_minutes | Integer | 采集间隔(分钟) |
| paused | Boolean | 是否暂停采集 |
| tags | String(500) | 自定义标签(分号分隔) |
| fail_count | Integer | 连续失败次数 |
| last_error | Text | 最近错误信息 |

### 2.4 db/ — 数据访问层

```
db/
├── __init__.py        → 导出 Repository
├── session.py         → 引擎/会话/建表(使用 get_settings())
└── repository.py      → Repository 模式封装所有 CRUD
```

**Repository** 封装所有数据库操作, 上层不直接操作 Session:
- Anime CRUD + upsert
- AnimeStat 追加 + 按时间查询
- Episode CRUD + sync(插入/更新)
- EpisodeStat 批量追加 + 最新查询
- CrawlTask 状态管理(含 paused 过滤 get_due_tasks)

### 2.5 core/ — 核心业务层

```
core/
├── __init__.py         → 导出 Pipeline, Orchestrator, Scheduler, Analyzer, TrackingTable
├── pipeline.py         → 数据管道:fetch → transform → store
├── orchestrator.py     → 任务编排(使用 ClientFactory)
├── scheduler.py        → 定时调度器(按平台路由)
├── analyzer.py         → 数据分析查询(使用 Repository)
└── tracking.py         → CSV追踪表管理(新增)
```

**Pipeline** — 单次采集的数据流转:

```
Pipeline(repo, BaseClient)
├── fetch_and_save_anime(season_id, platform) → API获取 → ORM → DB
├── fetch_and_save_anime_stat(season_id)      → 统计快照 → DB
├── fetch_and_save_episodes(season_id)        → 集数列表 → sync → DB
├── fetch_and_save_episode_stats(season_id)   → 并发VideoStat → DB
├── crawl_once(season_id, platform)           → 上述全部流程
└── create_crawl_task(season_id, platform)    → 创建采集任务
```

**Orchestrator** — 业务编排层:

```
Orchestrator
├── add_anime(keyword/season_id) → 搜索/选择 → 创建 → 首次采集
├── crawl_once(season_id, platform) → 单动画采集 + 任务状态更新
└── crawl_all()                 → 全量采集
```

**Scheduler** — 定时调度器:

```
Scheduler.start()
  → 每隔 schedule_check_seconds 秒
  → Repository.get_due_tasks()  [跳过 paused=True 的任务]
  → 按 task.platform 路由:ClientFactory.create(platform)
  → Pipeline.crawl_once(season_id, platform)
  → 成功/失败 → mark_task_success/failed
```

**TrackingTable** — CSV追踪表管理器:

```
TrackingTable
├── load() → list[TrackingTarget]           # 读取CSV
├── validate(targets) → list[str]           # 校验(平台、ID、优先级)
├── sync_to_db(targets) → (created, updated) # 同步到CrawlTask
├── crawl_all(targets)                      # 按平台路由依次采集
└── create_template(path)                   # 创建CSV模板
```

**Tracking CSV 格式:**

```csv
platform,season_id,title,priority,interval_minutes,paused,tags
bilibili,425,咒术回战 第二季,0,60,false,2024秋;热血
bilibili,39567,葬送的芙莉莲,1,120,false,
```

**Analyzer** — 数据分析(使用 Repository, 不直接操作 Session):

```
Analyzer
├── get_anime_list() → DataFrame
├── get_anime_overview(season_id) → DataFrame
├── get_episode_detail(season_id) → DataFrame
├── get_daily_diff(season_id, days) → DataFrame
└── get_episode_rank(season_id) → DataFrame
```

### 2.6 export/ — 导出层

与旧版相同, 使用 `get_settings()` 获取路径配置。

### 2.7 utils/ — 工具层

```
utils/
├── __init__.py
└── rate_limiter.py   → 异步令牌桶限速器
```

**RateLimiter** — 基于令牌桶算法的异步限速器:
- `rate`: 每秒请求数(默认2.5, 即0.4s间隔)
- `burst`: 突发容量(默认3)
- `acquire()`: async 方法, 获取一个令牌

## 3. 数据流

### 3.1 添加动画流程

```
用户 → add "咒术回战"
     → Orchestrator.add_anime()
        → ClientFactory.create("bilibili")
        → BilibiliClient.search() [异步]
        → 用户选择
        → BilibiliClient.get_season_info() [异步]
        → Pipeline.transform → Repository.store
        → 创建 CrawlTask (platform="bilibili")
     → 首次完整采集
```

### 3.2 批量导入流程

```
用户 → import data/tracking.csv [或 --file 指定]
     → TrackingTable.load()
         → 读取 CSV, 解析为 list[TrackingTarget]
     → TrackingTable.validate()
         → 校验 platform/season_id/priority
     → TrackingTable.sync_to_db()
         → 已存在 → update CrawlTask
         → 不存在 → create CrawlTask
     → TrackingTable.crawl_all()
         → 暂停项跳过
         → 不存在 → Orchestrator.add_anime()
         → 已存在 → Orchestrator.crawl_once(platform)
```

### 3.3 定时调度流程

```
Scheduler.start()
  → 每 check_interval 秒
  → Repository.get_due_tasks()
     → 过滤 paused=False
     → 按 priority 排序
  → 遍历每个任务:
     → ClientFactory.create(task.platform)
     → Pipeline.crawl_once(task.season_id, task.platform)
     → 更新 CrawlTask 状态
        成功 → mark_task_success (计算 next_crawl_at)
        失败 → mark_task_failed (指数退避)
```

### 3.4 暂停/恢复流程

```
用户 → pause 425 → Repository.toggle_pause(425, True)
用户 → resume 39567 → Repository.toggle_pause(39567, False)
```

### 3.5 导出流程

```
用户 → export --name "咒术回战" --format excel
     → Analyzer.get_anime_list() → 模糊匹配
     → ExcelWriter.export(season_id, name)
         → Analyzer.get_anime_overview() → Sheet: 动画总览
         → Analyzer.get_episode_detail()  → Sheet: 单集明细
         → Analyzer.get_daily_diff()      → Sheet: 每日增量
         → Analyzer.get_episode_rank()    → Sheet: 单集排行
```

**分层原则:**
- client 层不依赖 db/models
- pipeline 层同时依赖 client 和 db(数据桥梁)
- orchestrator 不直接操作模型, 通过 Pipeline/Repository
- tracking 层通过 Orchestrator 调度, 不直接使用客户端
- analyzer 仅依赖 db(通过 Repository)
- export 层仅依赖 analyzer

## 6. 错误处理与容错

| 场景 | 处理方式 |
|------|---------|
| API返回非0 code | 记录警告日志, 返回None |
| 网络超时/5xx | tenacity重试3次, 指数退避(2-30s) |
| 单集数据缺失 | EpisodeStat跳过, 不阻塞其他集 |
| 动画不存在 | 日志记录, 不影响其他动画 |
| CSV格式错误 | 记录警告, 跳过错误行 |
| 不支持的平台 | ClientFactoryError + 日志记录 |
| 数据库操作 | session.rollback() + re-raise |
| 快照不足 | diff命令提示"需要至少采集2天" |
| 采集失败 | CrawlTask指数退避(1min→2min→...→24h) |
